The files in this folder are for the local development container and the CI
end-to-end tests only. Do not use them to provision a production Grafana: a
production install must start with an empty allowlist.

For more information see our documentation:

- [Provision Grafana](https://grafana.com/docs/grafana/latest/administration/provisioning/)
- [Provision a plugin](https://grafana.com/developers/plugin-tools/publish-a-plugin/provide-test-environment)
